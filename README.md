I'm an agronomist with a background in precision agriculture, working at the intersection of **agribusiness, market intelligence and technology**.

At **Céleres**, I contribute to projects involving agricultural data analysis, geospatial modeling, data engineering, automation and applied AI. I aim to turn complex datasets and scientific methodologies into practical tools that support better decisions.

## 🌱 Selected work

Most projects are developed in private repositories or internal environments. The descriptions below highlight their analytical scope without exposing proprietary code or data.

| Project | Focus | Stack |
|---|---|---|
| **In-season soybean monitoring (EVI)** | Pilot using satellite time series to compare municipal crop signals with historical patterns and explore yield estimates | Python · Remote sensing |
| **Early crop-area estimation** | Methodology and pilot design for early soybean and first- and second-crop corn area estimates (in development; model training pending) | Python · Remote sensing |
| **Agricultural data pipelines** | Collection, standardization and quality controls for public agricultural datasets; cloud data architecture in evolution | Python · SQL · Power Query |
| **Crop protection data integration** | Auditable integration of IBAMA, Agrofit and Conab records, including active-ingredient classification and manual validation | Python · SQLite |
| **Agricultural input price intelligence** | Internal tools for price monitoring, regional comparisons and geospatial visualization (under validation) | Python · JavaScript · GIS |
| **Agricultural land suitability scoring** | Geospatial assessments and PDF reports for rural properties using CAR/SICAR and public data layers | Python · GeoPandas · GIS |

Also working with productive-potential modeling and irrigation scenarios.
