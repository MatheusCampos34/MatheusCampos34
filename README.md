I'm an agronomist with a background in precision agriculture, working at the intersection of **agribusiness, market intelligence and technology**.

At **Céleres**, I contribute to data-driven initiatives involving **ETL pipelines, data quality, workflow automation, geospatial analytics and applied AI**. My focus is turning complex information into reliable tools for agricultural and business decisions.

## 🌱 Selected work

A high-level overview of contributions and research. Most work is developed in private environments; proprietary code, datasets and operational details are not shared.

| Project area | What I work on | Stack |
|---|---|---|
| **Agricultural ETL & data integration** | Extracting, transforming, validating and consolidating external datasets into reproducible analytical workflows | Python · SQL · Azure |
| **Data workflow automation** | Reusable processing components, automated quality checks and repeatable data updates | Python · GitHub Actions |
| **In-season crop monitoring** | Pilot analyses using satellite time series to compare crop signals with historical patterns and explore yield indicators | Python · Remote sensing |
| **Early crop-area estimation (R&D)** | Methodologies for monitoring and estimating planted area ahead of final seasonal reporting | Python · GIS |
| **Crop protection data analytics** | Integration and standardized classification of public agricultural records, with quality controls | Python · SQLite |
| **Agricultural input price intelligence** | Regional comparisons, price monitoring and geospatial visualization for decision support | Python · JavaScript · GIS |
| **Agricultural land suitability scoring** | Geospatial assessments and automated reporting for rural properties using public spatial data | Python · GeoPandas · GIS |

Also working with productive-potential modeling and irrigation scenarios.
